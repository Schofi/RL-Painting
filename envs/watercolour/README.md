# RL Painting environment

The OpenEnv service renders p5.brush sketches in Chromium and scores the images.
Build the Dockerfile from this directory so that both `openenv/` and `core/` are included.
The [standalone repository](https://github.com/Schofi/RL-Painting) contains the training recipe and scorer configuration.
